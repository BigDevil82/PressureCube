# 高海拔增压建筑智能设计系统

基于层次图机器学习的三维钢框架优化设计系统，用于高海拔增压建筑的结构优化设计。

## 功能特点

- 基于层次图嵌入(HEBG)的结构表示
- 强化学习驱动的结构优化
- OpenSees结构分析集成
- 自动约束校核
- 多目标优化（质量最小化、满足强度刚度要求）
- 智能钢板蒙皮生成

## 系统要求

- Python 3.8+
- PyTorch 1.9+
- PyTorch Geometric 2.0+
- OpenSees 3.3.0+
- 其他依赖见 requirements.txt

## 安装

1. 克隆仓库：
```bash
git clone https://github.com/BigDevil82/PressureCube.git
cd PressureCube
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 使用方法

1. 准备配置文件：
修改 `config.yaml` 中的参数，包括舱体尺寸、窗户位置等。

2. 可视化结构模型：
```bash
python main.py --mode visualize --config config.yaml
```

3. 训练优化智能体：
```bash
python main.py --mode train --config config.yaml
```

4. 测试优化结果：
```bash
python main.py --mode test --config config.yaml
```

## 建模方法说明

### 网格化建模

为了更准确地反映结构连接关系和分析受力情况，本系统实现了网格化建模方法，主要特点包括：

1. **网格点生成**：按照主梁、次梁和支撑梁的间距要求，在各个方向上生成网格点
2. **构件分段**：将长直梁按照与其他构件的交点分段，确保节点处构件的连接关系正确
3. **构件类型划分**：根据构件在结构中的位置和功能，自动分配为框架梁、主梁、次梁或支撑梁
4. **动态网格**：根据主梁和次梁间距参数，动态生成合理的网格布局

### 智能钢板蒙皮生成系统

**新增功能**：在生成梁构件的基础上，系统现在能够自动识别并生成钢板蒙皮，形成完整的舱体外壳。

#### 核心特点

1. **基于梁栅格的板生成**：
   - 不是简单基于节点生成板，而是基于实际的梁构件布局
   - 确保每块板的四条边都有对应的梁构件支撑
   - 避免在没有梁的区域误生成钢板

2. **智能网格识别**：
   - 针对每个面（顶面、底面、前面、后面、左面、右面）分别处理
   - 自动识别该面上的所有梁构件并按方向分类
   - 基于正交梁构件形成的真实栅格确定板的位置

3. **窗户区域避让**：
   - 自动检测窗户和门的位置
   - 在窗户区域不生成钢板
   - 保持结构完整性的同时确保开口正确

4. **节点顺序优化**：
   - 所有钢板的节点按逆时针方向排列
   - 不同面采用不同的排序策略，确保从外侧观看时的一致性
   - 便于后续的渲染和分析

#### 技术实现

1. **Plate类设计**：
   ```python
   @dataclass
   class Plate:
       id: int
       nodes: List[int]  # 4个节点ID，按逆时针方向排列
       on_face: str      # 所在面
       thickness: float  # 板厚，默认10mm
   ```

2. **智能生成算法**：
   - `_generate_face_plates()`: 基于梁构件确定网格坐标线
   - `_check_rectangle_has_beams()`: 验证矩形四边是否都有梁支撑
   - `_is_in_window_area()`: 检查是否与窗户区域重叠
   - `_order_nodes_counterclockwise()`: 按逆时针方向排序节点

3. **质量计算集成**：
   - 在结构总质量计算中包含钢板质量
   - 考虑板厚、面积和钢材密度
   - 提供详细的质量分解

#### 应用效果

- **准确性**：确保钢板只在有梁支撑的区域生成
- **完整性**：自动处理复杂的窗户和门洞配置
- **高效性**：简洁的算法实现，避免代码臃肿
- **可扩展性**：易于添加新的板类型和特殊处理逻辑

### 前后立面建模

前后立面（位于YZ平面上）的建模方法，考虑了窗户的位置和尺寸：

1. **主梁布置**：沿Z轴方向（竖直方向）布置主梁，按照主梁间距参数来确定
2. **窗户梁适配**：
   - 在窗户底部和顶部位置设置水平次梁
   - 在窗户左右边缘设置竖直次梁
   - 窗户区域内不布置任何梁构件
3. **支撑梁布置**：
   - 在窗户上下区域，根据支撑梁间距参数布置水平支撑梁
   - 窗户之间的区域根据支撑梁间距参数布置支撑梁
4. **框架梁设置**：在立面的四个边缘布置框架梁，提供整体刚度

### 左右侧面建模

左右侧面（位于XZ平面上）的建模方法，考虑了窗户和门的位置与尺寸：

1. **主梁布置**：沿Z轴方向（竖直方向）布置主梁，采用跨中对称布置方式
   - 首先在跨中位置设置一根主梁
   - 然后向左右两侧按照主梁间距扩展布置其余主梁
2. **窗户和门的适配**：
   - 在窗户/门底部和顶部位置设置水平次梁
   - 在窗户/门左右边缘设置竖直主梁
   - 窗户/门区域内不布置任何梁构件
   - 特别支持门从地面开始的情况
3. **支撑梁布置**：
   - 在窗户/门上下区域，根据支撑梁间距参数布置水平支撑梁
   - 如果没有窗户/门，则均匀布置支撑梁
4. **框架梁设置**：在立面的四个边缘布置框架梁，提供整体刚度

这种建模方法不仅能够适应任意窗户和门的配置，还可以根据指定的间距参数动态调整结构布局。

### ETABS模型生成接口

新增功能：系统现在能够将内部的`StructuralModel`对象（包含节点、梁、板及截面信息）转换为一个完整的ETABS有限元分析模型。这是通过Python脚本与ETABS的COM (Component Object Model) 接口进行交互来实现的。

#### 核心功能

1.  **自动化建模**：
    *   从`StructuralModel`实例中读取几何信息（节点坐标、梁的连接关系、板的节点组成）和属性信息（截面参数、板厚、材料类型）。
    *   自动在ETABS中创建对应的节点、框架单元（梁）和壳单元（板）。

2.  **单位和材料管理**：
    *   在ETABS模型中统一使用 **N, mm, °C** 单位制。
    *   自动定义所需材料，例如常用的Q345钢材，并设置其物理属性（弹性模量、泊松比、热膨胀系数、屈服强度、极限强度）。

3.  **截面定义**：
    *   **梁截面**：根据`StructuralModel`中`SteelSection`对象提供的属性（如面积、主惯性矩I33和I22、抗扭惯性矩J、主副方向截面模量S33和S22等），在ETABS中定义为"通用截面"(General Section)。假设`SteelSection`中的属性值已按mm单位制提供（如面积mm²，惯性矩mm⁴）。
    *   **板截面**：根据`Plate`对象的厚度（假设在`StructuralModel`中以米为单位，自动转换为mm）定义对应的壳单元截面属性。

4.  **构件创建与属性分配**：
    *   **节点**：精确创建所有节点，坐标从米转换为毫米。
    *   **梁单元**：连接对应节点，并赋予先前定义的梁截面属性。
    *   **板单元**：基于节点连接创建，并赋予对应的板壳截面属性。

5.  **ETABS实例管理**：
    *   脚本支持启动新的ETABS实例或附加到已运行的ETABS实例。
    *   包含错误处理和操作结果反馈。

#### 使用示例 (`src/analysis/create_etabs_model.py`)

脚本`create_etabs_model.py`内含一个`build_etabs_model`函数，接收一个`StructuralModel`对象作为输入。同时，该文件末尾的`if __name__ == '__main__':`部分提供了一个如何实例化一个简单的`StructuralModel`并调用此函数生成ETABS模型的示例。生成后的模型可以被保存为`.EDB`文件。

#### 主要优势

-   **设计-分析流程自动化**：打通了从参数化结构定义到专业结构分析软件模型的转换，为后续的性能评估和优化迭代奠定基础。
-   **一致性和准确性**：确保了ETABS模型与内部`StructuralModel`的一致性，减少手动建模错误。
-   **可扩展性**：未来可以进一步扩展，例如自动施加荷载、定义组合、运行分析、提取结果等。

    - **模型构建**: 自动化创建OpenSees模型，包括节点、梁单元（elasticBeamColumn）、板单元（ShellMITC4）、材料（ElasticIsotropic, ElasticMembranePlateSection）、几何变换、边界条件和节点质量。
    - **荷载施加**:
        - 支持梁单元的重力荷载（均布荷载）。
        - 支持板单元的均布压力荷载（通过等效梁荷载施加到板的边界梁上）。
        - 提供组合重力与压力荷载的功能。
    - **分析执行**:
        - 静力分析。
        - 模态分析。
    - **结果提取**:
        - 节点位移。
        - 支座反力。
        - 板单元节点位移和中心位移。
        - 板单元反力（`forces` - Nxx, Nyy, Nxy, Mxx, Myy, Mxy, Vxz, Vyz）。
        - 板单元应力（`stresses` - 32个值，代表4个Gauss点上下表面的σxx, σyy, τxy, τzz）。
    - **结果后处理与保存**:
        - `analyze_plate_deformation`: 分析板的变形特性，包括最大节点位移、平均中心位移等。
        - **新增功能**: 计算并报告所有板中的最大绝对正应力（σxx 或 σyy）及其所在的板单元ID。
        - 结果以JSON格式保存。
        - **完整分析流程**: `perform_full_analysis_and_save` 方法封装了从模型设置、荷载施加、分析执行到结果保存的完整流程。
