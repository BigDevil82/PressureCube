# 高海拔增压建筑智能设计系统

基于层次图机器学习的三维钢框架优化设计系统，用于高海拔增压建筑的结构优化设计。

## 功能特点

- 基于层次图嵌入(HEBG)的结构表示
- 强化学习驱动的结构优化
- OpenSees结构分析集成
- 自动约束校核
- 多目标优化（质量最小化、满足强度刚度要求）

## 系统要求

- Python 3.8+
- PyTorch 1.9+
- PyTorch Geometric 2.0+
- OpenSees 3.3.0+
- 其他依赖见 requirements.txt

## 安装

1. 克隆仓库：
```bash
git clone [repository_url]
cd [repository_name]
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 使用方法

1. 准备配置文件：
修改 `config.yaml` 中的参数，包括舱体尺寸、窗户位置等。

2. 可视化结构模型：
```bash
python main.py --mode visualize --config config.yaml
```

3. 训练优化智能体：
```bash
python main.py --mode train --config config.yaml
```

4. 测试优化结果：
```bash
python main.py --mode test --config config.yaml
```

## 建模方法说明

### 网格化建模

为了更准确地反映结构连接关系和分析受力情况，本系统实现了网格化建模方法，主要特点包括：

1. **网格点生成**：按照主梁、次梁和支撑梁的间距要求，在各个方向上生成网格点
2. **构件分段**：将长直梁按照与其他构件的交点分段，确保节点处构件的连接关系正确
3. **构件类型划分**：根据构件在结构中的位置和功能，自动分配为框架梁、主梁、次梁或支撑梁
4. **动态网格**：根据主梁和次梁间距参数，动态生成合理的网格布局

### 前后立面建模

前后立面（位于YZ平面上）的建模方法，考虑了窗户的位置和尺寸：

1. **主梁布置**：沿Z轴方向（竖直方向）布置主梁，按照主梁间距参数来确定
2. **窗户梁适配**：
   - 在窗户底部和顶部位置设置水平次梁
   - 在窗户左右边缘设置竖直次梁
   - 窗户区域内不布置任何梁构件
3. **支撑梁布置**：
   - 在窗户上下区域，根据支撑梁间距参数布置水平支撑梁
   - 窗户之间的区域根据支撑梁间距参数布置支撑梁
4. **框架梁设置**：在立面的四个边缘布置框架梁，提供整体刚度

### 左右侧面建模

左右侧面（位于XZ平面上）的建模方法，考虑了窗户和门的位置与尺寸：

1. **主梁布置**：沿Z轴方向（竖直方向）布置主梁，采用跨中对称布置方式
   - 首先在跨中位置设置一根主梁
   - 然后向左右两侧按照主梁间距扩展布置其余主梁
2. **窗户和门的适配**：
   - 在窗户/门底部和顶部位置设置水平次梁
   - 在窗户/门左右边缘设置竖直主梁
   - 窗户/门区域内不布置任何梁构件
   - 特别支持门从地面开始的情况
3. **支撑梁布置**：
   - 在窗户/门上下区域，根据支撑梁间距参数布置水平支撑梁
   - 如果没有窗户/门，则均匀布置支撑梁
4. **框架梁设置**：在立面的四个边缘布置框架梁，提供整体刚度

这种建模方法不仅能够适应任意窗户和门的配置，还可以根据指定的间距参数动态调整结构布局。
