# 高海拔增压建筑智能设计系统

基于层次图机器学习的三维钢框架优化设计系统，用于高海拔增压建筑的结构优化设计。

## 功能特点

- 基于层次图嵌入(HEBG)的结构表示
- 强化学习驱动的结构优化
- OpenSees结构分析集成
- 自动约束校核
- 多目标优化（质量最小化、满足强度刚度要求）
- 智能钢板蒙皮生成

## 系统要求

- Python 3.9.12
- PyTorch 1.9+
- PyTorch Geometric
- 其他依赖见 requirements.txt

## 安装

1. 克隆仓库：
```bash
git clone https://github.com/BigDevil82/PressureCube.git
cd PressureCube
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 使用方法

1. 准备配置文件：
修改 `config.yaml` 中的参数，包括舱体尺寸、窗户位置等。

2. 可视化结构模型：
```bash
python main.py --mode visualize --config config.yaml
```

3. 训练优化智能体：
```bash
python main.py --mode train --config config.yaml
```

4. 测试优化结果：
```bash
python main.py --mode test --config config.yaml
```

5. 运行收敛性分析（找到理论最优解）：
```bash
python main.py --mode convergence --config config.yaml
```

## 建模方法说明

### 网格化建模

为了更准确地反映结构连接关系和分析受力情况，本系统实现了网格化建模方法，主要特点包括：

1. **网格点生成**：按照主梁、次梁和支撑梁的间距要求，在各个方向上生成网格点
2. **构件分段**：将长直梁按照与其他构件的交点分段，确保节点处构件的连接关系正确
3. **构件类型划分**：根据构件在结构中的位置和功能，自动分配为框架梁、主梁、次梁或支撑梁
4. **动态网格**：根据主梁和次梁间距参数，动态生成合理的网格布局

### 智能钢板蒙皮生成系统

**新增功能**：在生成梁构件的基础上，系统现在能够自动识别并生成钢板蒙皮，形成完整的舱体外壳。

#### 核心特点

1. **基于梁栅格的板生成**：
   - 不是简单基于节点生成板，而是基于实际的梁构件布局
   - 确保每块板的四条边都有对应的梁构件支撑
   - 避免在没有梁的区域误生成钢板

2. **智能网格识别**：
   - 针对每个面（顶面、底面、前面、后面、左面、右面）分别处理
   - 自动识别该面上的所有梁构件并按方向分类
   - 基于正交梁构件形成的真实栅格确定板的位置

3. **窗户区域避让**：
   - 自动检测窗户和门的位置
   - 在窗户区域不生成钢板
   - 保持结构完整性的同时确保开口正确

4. **节点顺序优化**：
   - 所有钢板的节点按逆时针方向排列
   - 不同面采用不同的排序策略，确保从外侧观看时的一致性
   - 便于后续的渲染和分析

#### 技术实现

1. **Plate类设计**：
   ```python
   @dataclass
   class Plate:
       id: int
       nodes: List[int]  # 4个节点ID，按逆时针方向排列
       on_face: str      # 所在面
       thickness: float  # 板厚，默认10mm
   ```

2. **智能生成算法**：
   - `_generate_face_plates()`: 基于梁构件确定网格坐标线
   - `_check_rectangle_has_beams()`: 验证矩形四边是否都有梁支撑
   - `_is_in_window_area()`: 检查是否与窗户区域重叠
   - `_order_nodes_counterclockwise()`: 按逆时针方向排序节点

3. **质量计算集成**：
   - 在结构总质量计算中包含钢板质量
   - 考虑板厚、面积和钢材密度
   - 提供详细的质量分解

#### 应用效果

- **准确性**：确保钢板只在有梁支撑的区域生成
- **完整性**：自动处理复杂的窗户和门洞配置
- **高效性**：简洁的算法实现，避免代码臃肿
- **可扩展性**：易于添加新的板类型和特殊处理逻辑

### 结构网格划分

为了满足有限元分析对网格精度的要求，系统新增了独立的结构网格划分模块 (`MeshGenerator`)。该模块能够对已生成的`StructuralModel`进行二次处理，将其中的梁和板单元细分为更小的单元，从而生成一个全新的、网格更精细的`StructuralModel`。

#### 核心特点

1.  **可定制的网格尺寸**：
    *   用户可以通过`MeshParameters`指定梁单元和板单元的最大允许长度。
    *   模块将根据此参数自动计算所需的划分密度。

2.  **梁-板网格一致性**：
    *   这是此模块最核心的优势。板的网格划分不再使用简单的双线性插值，而是严格依赖其**边界梁**的网格划分结果。
    *   系统首先对所有梁进行细分，然后基于构成每块板边界的梁上的新节点来生成板的网格。
    *   这从根本上保证了细分后，板的边缘节点与相邻梁上的节点是**完全重合**的，避免了有限元模型中的不连续和应力传递问题。

3.  **复杂边界处理**：
    *   完美支持板的边界由多段梁（即边界上存在中间节点）构成的复杂情况。
    *   通过基于几何共线性的算法准确识别构成每条边的梁序列，并沿该序列生成一致的网格节点。

#### 技术实现

1.  **MeshGenerator类**：
    *   接收原始的`StructuralModel`和`MeshParameters`作为输入。
    *   内部包含`_mesh_beams`和`_mesh_plates`两个核心方法，分别处理梁和板的划分。

2.  **两阶段划分流程**：
    *   **第一阶段（梁）**：遍历所有梁，根据`beam_max_length`将其划分为多段，生成新的节点和梁段。并将每条原始梁与其新生成的节点序列对应起来，存入缓存。
    *   **第二阶段（板）**：遍历所有板，利用`boundary_beams`信息找到其边界梁。通过几何算法识别并排序构成每条边的梁链，从缓存中获取这些梁上的节点，从而构建出板的四条边上的完整节点序列。最后，基于这四条边上的节点生成新的、更小的板单元。

#### 应用效果

-   **精度**：为有限元分析提供了高质量、高精度的网格。
-   **一致性**：确保了结构模型的几何连续性，是后续准确分析的基础。
-   **灵活性**：能够处理由复杂构件组成的任意结构模型。

### 前后立面建模

前后立面（位于YZ平面上）的建模方法，考虑了窗户的位置和尺寸：

1. **主梁布置**：沿Z轴方向（竖直方向）布置主梁，按照主梁间距参数来确定
2. **窗户梁适配**：
   - 在窗户底部和顶部位置设置水平次梁
   - 在窗户左右边缘设置竖直次梁
   - 窗户区域内不布置任何梁构件
3. **支撑梁布置**：
   - 在窗户上下区域，根据支撑梁间距参数布置水平支撑梁
   - 窗户之间的区域根据支撑梁间距参数布置支撑梁
4. **框架梁设置**：在立面的四个边缘布置框架梁，提供整体刚度

### 左右侧面建模

左右侧面（位于XZ平面上）的建模方法，考虑了窗户和门的位置与尺寸：

1. **主梁布置**：沿Z轴方向（竖直方向）布置主梁，采用跨中对称布置方式
   - 首先在跨中位置设置一根主梁
   - 然后向左右两侧按照主梁间距扩展布置其余主梁
2. **窗户和门的适配**：
   - 在窗户/门底部和顶部位置设置水平次梁
   - 在窗户/门左右边缘设置竖直主梁
   - 窗户/门区域内不布置任何梁构件
   - 特别支持门从地面开始的情况
3. **支撑梁布置**：
   - 在窗户/门上下区域，根据支撑梁间距参数布置水平支撑梁
   - 如果没有窗户/门，则均匀布置支撑梁
4. **框架梁设置**：在立面的四个边缘布置框架梁，提供整体刚度

这种建模方法不仅能够适应任意窗户和门的配置，还可以根据指定的间距参数动态调整结构布局。

### ETABS模型生成接口

新增功能：系统现在能够将内部的`StructuralModel`对象（包含节点、梁、板及截面信息）转换为一个完整的ETABS有限元分析模型。这是通过Python脚本与ETABS的COM (Component Object Model) 接口进行交互来实现的。

#### 核心功能

1.  **自动化建模**：
    *   从`StructuralModel`实例中读取几何信息（节点坐标、梁的连接关系、板的节点组成）和属性信息（截面参数、板厚、材料类型）。
    *   自动在ETABS中创建对应的节点、框架单元（梁）和壳单元（板）。

2.  **单位和材料管理**：
    *   在ETABS模型中统一使用 **N, mm, °C** 单位制。
    *   自动定义所需材料，例如常用的Q345钢材，并设置其物理属性（弹性模量、泊松比、热膨胀系数、屈服强度、极限强度）。

3.  **截面定义**：
    *   **梁截面**：根据`StructuralModel`中`SteelSection`对象提供的属性（如面积、主惯性矩I33和I22、抗扭惯性矩J、主副方向截面模量S33和S22等），在ETABS中定义为"通用截面"(General Section)。假设`SteelSection`中的属性值已按mm单位制提供（如面积mm²，惯性矩mm⁴）。
    *   **板截面**：根据`Plate`对象的厚度（假设在`StructuralModel`中以米为单位，自动转换为mm）定义对应的壳单元截面属性。

4.  **构件创建与属性分配**：
    *   **节点**：精确创建所有节点，坐标从米转换为毫米。
    *   **梁单元**：连接对应节点，并赋予先前定义的梁截面属性。
    *   **板单元**：基于节点连接创建，并赋予对应的板壳截面属性。

5.  **ETABS实例管理**：
    *   脚本支持启动新的ETABS实例或附加到已运行的ETABS实例。
    *   包含错误处理和操作结果反馈。

#### 使用示例 (`src/analysis/create_etabs_model.py`)

脚本`create_etabs_model.py`内含一个`build_etabs_model`函数，接收一个`StructuralModel`对象作为输入。同时，该文件末尾的`if __name__ == '__main__':`部分提供了一个如何实例化一个简单的`StructuralModel`并调用此函数生成ETABS模型的示例。生成后的模型可以被保存为`.EDB`文件。

#### 主要优势

-   **设计-分析流程自动化**：打通了从参数化结构定义到专业结构分析软件模型的转换，为后续的性能评估和优化迭代奠定基础。
-   **一致性和准确性**：确保了ETABS模型与内部`StructuralModel`的一致性，减少手动建模错误。
-   **可扩展性**：未来可以进一步扩展，例如自动施加荷载、定义组合、运行分析、提取结果等。

### 代理模型数据生成

为了训练能够快速预测结构响应的代理模型（Surrogate Model），我们开发了专门的数据集生成脚本。该脚本能够自动化地、大批量地生成结构样本并运行有限元分析，为机器学习模型的训练提供数据支持。

#### 核心功能

1.  **参数化随机结构**：
    *   脚本调用 `RandomStructure` 类，对结构的关键参数进行随机化，包括：`length`, `main_beam_spacing`, `brace_spacing`, 以及各类构件的截面索引和内部压力 `pressure`。
2.  **自动化分析流程**：
    *   对每个随机生成的结构，自动完成建模、网格划分、施加荷载和运行OpenSees静态分析的全过程。
3.  **数据采集与存储**：
    *   脚本会记录每一组输入的随机参数，并从分析结果中提取关键性能指标，即最大应力和最大位移。
    *   所有数据（输入参数和输出指标）被整理并保存为CSV格式文件，位于 `results/surrogate_model_dataset/` 目录下，便于后续直接用于模型训练。
4.  **可配置性**：
    *   在生成数据集时，可以选择不生成窗户，以简化模型，专注于主要结构参数对性能的影响。

#### 使用方法

直接运行脚本即可开始生成数据：
```bash
python src/surrogate_model/generate_dataset.py
```
可以修改脚本中的 `num_samples` 参数来控制生成样本的数量。

### 原型验证与模型优选

为了验证训练出的智能体的泛化能力和优化效果，系统引入了一套标准化的原型验证流程。该流程旨在通过一组固定的、有代表性的结构设计（即“原型”），对训练过程中保存的多个模型检查点进行横向比较，最终选出综合表现最佳的模型。

#### 核心功能

1.  **标准化测试集**：
    *   在 `src/structure/prototypes.py` 中定义了一系列原型结构。这些原型具有不同的几何参数（如长度），代表了模型在实际应用中可能遇到的不同工况。
    *   这为所有待评估模型提供了一个公平、一致的测试基准。

2.  **自动化评估流程**：
    *   运行 `main.py` 的 `test` 模式后，系统会自动查找所有已保存的模型文件（`.pth`）。
    *   它会依次加载每个模型，并在**每一个**原型结构上运行一个完整的优化回合。

3.  **性能度量与模型筛选**：
    *   对于每个模型，系统会计算其在所有原型上获得的**平均奖励**作为其综合性能指标。
    *   在所有模型测试完毕后，系统会比较它们的平均奖励，将得分最高的模型识别为“最佳模型”。

4.  **结果保存与报告**：
    *   最佳模型会被自动复制并重命名为 `best_model.pth`，方便直接调用。
    *   同时，系统会在控制台打印一份详细的最终报告，内容包括：
        *   最佳模型的名称和其平均奖励。
        *   该模型在每个原型结构上的最终设计结果：最大位移、最大应力、材料用量，以及是否满足预设的设计约束（可行性）。

## 最新改进 (2024)

### PPO算法稳定性提升 🚀

经过深入分析PPO训练中的稳定性问题，我们实现了以下关键改进：

1. **两阶段奖励函数设计**：
   - **不可行阶段**：只奖励约束改善，不考虑体积变化，避免策略被误导
   - **可行阶段**：主要奖励体积最小化，包含从不可行到可行的突破奖励
   - 消除了奖励函数中的冲突信号，提升策略学习稳定性

2. **动作掩码机制**：
   - 自动识别当前状态下的无效动作（在边界继续增减截面）
   - 在策略网络输出前应用掩码，避免选择无效动作
   - 显著减少无效动作导致的策略塌陷问题

3. **PPO超参数优化**：
   - 降低学习率：5e-5（原1e-4）
   - 提高初始熵系数：0.05（原0.01）并添加衰减机制
   - 修复Adam优化器参数：betas=(0.9, 0.999)
   - 添加梯度裁剪和数值稳定性改进

4. **训练策略改进**：
   - 随机起点扰动：30%概率在初始截面附近随机扰动
   - 减少异常惩罚：-15（原-250），避免优势方差爆炸
   - 温和的无效动作惩罚：-0.5（原-20）

### 最优性评估系统 🎯

开发了完整的收敛性评估框架，解决"如何判断模型是否收敛到最优"的问题：

1. **穷举搜索算法**：
   - 自动搜索所有4×11×10×17=7,480种截面组合
   - 并行化计算，支持多进程加速
   - 找到每个压力条件下的理论最优解

2. **Optimality Gap计算**：
   - 自动计算智能体解与理论最优解的差距百分比
   - 支持多压力值下的性能对比
   - 生成详细的性能报告

3. **使用方法**：
   ```bash
   # 运行穷举搜索找到理论最优解
   python main.py --mode convergence
   
   # 测试训练好的模型并计算optimality gap
   python main.py --mode test
   ```

- **效率**：动作掩码显著减少无效探索
