# 梁分组算法说明

本模块用于在一个已经完成有限元分析的单模型上，将同一功能类型的梁进一步划分为若干截面组。目标不是替代结构校核，而是找出“受力和变形特征相近、空间位置也协调”的梁组，为后续更精细的截面优化提供依据。

## 输入

- `StructuralModel`：已经完成参数化建模和网格划分的结构模型。
- `strength_results`：强度组合分析结果，用于提取梁内力和应力指标。
- `service_results`：正常使用组合分析结果，用于提取节点位移指标。
- `BeamGroupConfig`：控制每种梁类型的组数、特征权重和镜像对称设置。

## 核心流程

1. 对每根非虚梁提取 `BeamFeature`。
2. 根据梁类型、方向、所在面类别和镜像折叠后的归一化中点坐标生成 `symmetry_key`。
3. 具有相同 `symmetry_key` 的梁合并为一个 symmetry orbit。
4. 对每一种 `BeamType` 单独聚类，避免框梁、主梁、次梁、支撑梁混合分组。
5. 聚类对象是 symmetry orbit 的均值特征，而不是单根梁。
6. 将 orbit 的聚类标签回填到每根梁，得到 `beam_id -> group_id`。

## 特征构成

聚类特征包括三类信息：

- 受力特征：最大应力比、最大应力。
- 变形特征：梁两端节点位移最大值、平均值、相对位移。
- 空间特征：归一化中点坐标、归一化梁长。

`beam_id` 不进入特征向量。它只是人为编号，仅用于把分组结果映射回模型和可视化。

## 对称性处理

`mirror_x`、`mirror_y`、`mirror_z` 控制是否把某个方向上的镜像位置视为同一位置。例如 `mirror_x=True` 时，归一化坐标 `x=0.2` 和 `x=0.8` 会折叠为同一个位置 `0.2`。这会强制近似对称梁进入同一个 symmetry orbit，从而分到同一截面组。

当前默认 `mirror_x=True`、`mirror_y=False`、`mirror_z=True`。这表示默认认为长度方向和高度方向有镜像协调需求，但不强制宽度方向镜像。这个假设可以通过 `BeamGroupConfig` 调整。

## 当前适用范围

当前结果只对本次固定拓扑模型稳定。若优化变量会改变主梁间距、支撑梁布置或门窗位置，则梁数量和编号都会变化，不应直接复用某次分析得到的 `beam_id -> group_id`。

更稳妥的优化流程是：先用该模块在若干代表性模型上发现分组规律，再把规律固化为基于几何位置和梁类型的规则函数，最后在优化中使用规则函数为每个新模型动态分配截面组。
