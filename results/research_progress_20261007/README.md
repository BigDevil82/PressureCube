## 逐页讲述要点

### 1. 研究背景与阶段目标

增压建筑的尺寸、内压和构件布置随项目需求变化，拓扑与截面组合形成较大的设计空间。有限元逐方案评估耗时，同类构件统一截面又限制了材料利用效率。本阶段分别从评估效率和设计自由度入手，研究代理模型辅助优化与构件分组优化。目标是满足应力、位移约束下的结构质量最小化。

### 2. 代理模型辅助优化方法

使用LHS采样及并行有限元获得结构响应标签，ResNet分别学习应力和位移利用率。遗传算法批量调用代理模型评估候选方案，质量由几何模型直接计算。代码在代理预测利用率超过0.9时开始施加惩罚，最终仍按真实有限元利用率不大于1.0判断可行。

当前线上接口为K折ResNet集成。23万样本、210维特征的单目标应力模型是独立实验资产，尚不能直接当作当前双目标优化接口的部署模型。示意网络与结构响应图用于解释流程，不是实际计算云图。

### 3. 构件分组优化方法

离线阶段对代表性结构进行有限元分析，提取应力、位移、位置、方向等特征，以对称等价组为聚类单位，按构件类型分别进行Ward层次聚类。聚类后保存几何原型，新模型根据类型和几何距离匹配组别，不需先分析当前候选结构，也不依赖固定构件编号。

典型设置为框架梁2组、主梁2组、次梁3组、支撑梁2组，共9个截面变量。最终有限元不满足时，现有`validate_and_repair`按照规则中记录的需求统计排序，逐组增大截面并复核，最多24步。因此不应将其描述为实时识别控制杆件后精确修复，也不能保证所有候选都能修复成功。

### 4. 代理模型成效

独立实验中，分组应力模型在23万样本、210维输入上测试R²为0.984994，MAE为0.056336；分组位移模型在20万样本、236维输入上测试R²为0.989791，MAE为0.060648。这两项来自不同数据集和独立模型，不代表同一联合模型，不用于严格比较两模型优劣。

本次实测采用当前部署的`src/data/engineering_group_model.pkl`。候选方案为7.2×3.6×3.3 m、内压20 kPa，主梁间距0.95 m，支撑梁最大间距0.5 m，设置支撑梁，有限元网格0.5 m。9组构件暂按各类型同截面初始化，索引为框架2、主梁8、次梁7、支撑14，质量15.626 t。它是单方案对照，不是优化后最优方案。

| 指标 | 有限元 | 当前部署代理模型 |
| --- | ---: | ---: |
| 应力利用率 | 0.729799 | 0.714359 |
| 位移利用率 | 0.556325 | 0.536122 |
| 单次评估中位耗时/s | 0.703243 | 0.055169 |

评估加速12.747倍。计时包含候选方案建模、质量计算和各自响应评估，排除模型加载与离线训练。代理模型预热后重复30次，有限元重复3次，使用同一台计算机串行实测。此结果不能外推为整个遗传算法流程的加速倍数。

### 5. 构件分组成效

使用项目既有文档记录的三个工程算例，固定各原型的不分组优化拓扑，再允许分组独立调整截面，隔离截面细分收益。三个原型宽3.6 m、高3.3 m，网格0.5 m。
